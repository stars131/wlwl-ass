# Tauri icons

Phase 0 ships **no real icons** — placeholder PNGs / `.ico` / `.icns` belong
here before the first packaged build.

Generate from a single source:

```bash
npx @tauri-apps/cli icon path/to/source.png
```

This writes `32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.icns`,
`icon.ico` next to this README.
